# HotFix Privacy Policy

HotFix does not collect, store, transmit, or share any personal information or user data.

The extension works locally in your browser to convert text typed using the wrong Arabic or English keyboard layout.

## Data Collection

HotFix does not collect:

- Personal information
- Browsing history
- Keystrokes
- Messages
- Authentication data
- Financial information
- Location data

## Remote Code

HotFix does not use remote code execution. All functionality is bundled directly within the extension package.

## Third-Party Services

HotFix does not use analytics, tracking tools, advertisements, or third-party data collection services.

## Permissions

The extension requires access to editable webpage content only to detect and replace selected text when the user explicitly triggers a shortcut.
